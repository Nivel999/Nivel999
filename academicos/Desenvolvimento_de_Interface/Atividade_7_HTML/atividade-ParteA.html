0. O que é HTML e características

É a linguagem usada para estruturar páginas na internet. Funciona através de tags (etiquetas) que organizam o conteúdo (textos, imagens, links). Não é linguagem de programação.

1. O que motivou a criação?

Foi criado em 1991 por Tim Berners-Lee para facilitar o compartilhamento de documentos e pesquisas científicas entre universidades pelo mundo.

2. Principais tags e utilidades

  • <html>, <head>, <body>: Formam a estrutura básica e visível da página.
  • <h1> a <h6>: Servem para criar os títulos.
  • <p>: Cria parágrafos de texto.
  • <a>: Insere links clicáveis.
  • <img>: Coloca imagens na tela.

3. Tabela de boas e más práticas

Boas Práticas Más Práticas
Alinhar e organizar o código (indentação) Esquecer de fechar as tags (ex: abrir <p> e não colocar </p>)
Usar tags que dão sentido ao texto (<header>, <footer>) Usar apenas a tag <div> para construir tudo
Descrever imagens (usar atributo alt) para acessibilidade Colocar visual/estilo (CSS) misturado direto no código HTML
